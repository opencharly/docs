## ci: sweep-based tag-on-merge dispatcher

### Summary of changes

Replaces the `pull_request: closed`-triggered tag dispatcher (which
never fires for auto-merges — the merge event action is `merged`, an
invalid trigger type) with the org-wide sweep shape: `workflow_run`
on the validator's completion + a 15-minute `schedule`, calling the
shared reusable in `opencharly/.github` (sweep-only, tags every
merged PR lacking its CalVer tag).

### How tested

The identical dispatcher + reusable are live in `opencharly/.github`
(PRs #61/#63/#65): the sweep tagged all missing merges
(v2026.233.2148 … v2026.234.0211). This repo's own merge will be
tagged by the sweep within minutes.
