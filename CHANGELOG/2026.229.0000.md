## A rename inverted a true retraction

An earlier round wrote a **correct** negation — "there is no `allStepKinds`", true because the
lowercase form exists in no module. The lowercase→uppercase sweep then hit that token **inside the
retraction** and capitalised it:

> the kind list is `AllStepKinds` (`sdk/deploykit/steps.go:104`) — there is no `AllStepKinds`.

which asserts and denies the same symbol in one sentence. `AllStepKinds` exists
(`sdk/deploykit/steps.go:104` → `spec/install_step_vocab.go:902`).

**A mechanical rename does not merely fail to fix a false sentence — it can invert a true one.** It is
also invisible to every existence check: the symbol resolves, so the sentence passes a grep in *both*
directions. The rule: **a negation is the one construction where a rename must never be applied
blind.**
