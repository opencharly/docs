### #143: the RCA, answered

hypothesised "catalog membership is undeclared". **The declared route always existed.** charly's
top-level `docs:` node — `charly.yml:3151-3173` at the pinned `b79851d` — declares exactly those
repos, verbatim:

```yaml

    docs:
        # sources — where the reference documentation is GENERATED from.
        sources:
            # compiled — the plugins compiled INTO this charly binary. The paths
            # are the schema defaults (this repo's own charly.yml + go.mod).
            compiled:
                enabled: true
                compiled_plugins_path: charly/charly.yml
                go_mod_path: charly/go.mod
            # release_repos — candies documented from the compiled corpus' go.mod
            # require pins (resolve via ITS require, else the latest CalVer tag).
            release_repos: [plugin-review, plugin-pipeline]
            # extra_repos — additional repos fetched + documented outside the
            # corpus, same require-else-tag resolution.
            extra_repos: [plugin-gh, plugin-docs]
```

which is precisely the resolution semantics #143's item 2 is about. The block is byte-identical at

missing — #143's searches covered `pins.tsv`,
`compiled_plugins:` and `@github` refs, but not the `docs:` node. What broke was the **resolution**
