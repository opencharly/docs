# 2026.227.0716 — rebrand to the Agent-in-the-Loop Factory

The product's positioning line changes from "the fully stocked gourmet kitchen
for you and your agents" to **the fully equipped factory floor for you and your
agents**, under the brand name **The Agent-in-the-Loop Factory**. This repo
carries the site half of that cutover.

## What landed

- **`astro.config.mjs`** — the site `<meta name="description">` moves onto the
  new tagline. This is the one remaining hand-maintained copy of the tagline
  anywhere: it lives in this repo while the generator that derives every other
  copy lives in the superproject, so no projection can reach it. Treat it as a
  known manual sync point.
- **`README.md`** — the repo's own tagline copy. Note it wraps mid-phrase, so a
  single-line grep for the old tagline does not find it.
- **`src/content/docs/concepts/00-vocabulary.md`** — the "note on the names"
  section gains the bridge paragraph reconciling the two registers. This is the
  page where a reader is most likely to feel the seam between a factory brand
  and a confectionery schema, so it is where the reconciliation is stated.
- **`src/content/docs/concepts/02-one-recipe-many-molds.md`** — drops the
  closing pun "A fully stocked kitchen really does ship with the sink", which
  only worked as a callback to the retired tagline. The tip itself and the
  "kitchen-sink dev boxes" idiom stay.
- **Regenerated trees** (`index.md`, `recipes/**`, `reference/**`) via
  `task docs:sync`. The regeneration is also a staleness catch-up: six pages are
  added and one route **disappears**
  (`/reference/candy/examplebuild-localpkg/`, whose candy no longer exists in
  the superproject). No route *moved*; one ceased to exist, which is permanent
  history worth recording. It had no inbound links.
- **`start/install.md` — install commands that do not exist are removed.** The
  page told readers to run `task build:pkg:arch|fedora|debian`, described as
  driving `charly box pkg`. None of those exist: `taskfiles/Build.yml` defines
  only `binary:` and `install-portable:`, and `charly box` has no `pkg`
  subcommand. Before this cutover both this page and the home page carried dead
  install commands, so they agreed by accident of staleness. Regenerating the
  home page changed what it said, which broke that accidental agreement and left
  the two contradicting each other — which is why the fix belongs to this
  cutover rather than being filed separately.

  Fixing this page was not sufficient on its own. The home page is generated
  from the superproject `README.md`, whose install section had its own three
  false claims: a `charly generate-packages` invocation, a "landing with the
  nFPM cutover / Until then" futures note of exactly the shape R4a forbids, and
  a `task` + `install -Dm755` recipe aimed at a reader the page defines as
  having no checkout. That README section was corrected in the same cutover and
  now points here instead; the home page in this commit is regenerated from the
  corrected source.

  This page now names only verified-live commands. Native packages are **not**
  described here — R4a is explicit that a silent page is recoverable while a
  page documenting a workaround teaches it, so there is no "coming soon" note
  either. Native packages ARE built, by the external
  `opencharly/plugin-generate-packages` plugin (released `v2026.227.0013`); this
  page will describe installing them once they are published to per-distro
  repos, which the nFPM packaging program owns. The duplicated
  `install-portable` section was folded into the install step it belongs to (R3).

## What did NOT change, deliberately

- **Routes and filenames.** Titles, labels and prose changed; no URL moved.
  `/recipes/` and every `/concepts/…` path is linked from the superproject
  README, from the generator's link-rewrite table, and from cross-references the
  build hard-fails on.
- **"Recipe cards" and "One recipe, many molds".** A production line runs on
  recipe cards and a mold is factory tooling — these read as MORE on-brand after
  the rebrand, not less.
- **The two pages that blockquote `VISION.md` tenets verbatim**
  (`concepts/04-you-and-your-agents.md`, `guides/authoring-a-plugin.md`).
  `VISION.md` is untouched, so the quotes remain accurate.

  A known and accepted consequence: the site therefore still publishes *"A
  gourmet kitchen: a tiny core, an all-you-can-eat buffet"* on `/vision/` and on
  `/guides/authoring-a-plugin/`. That is the retired kitchen vocabulary,
  surviving on two pages by deliberate decision — `VISION.md` keeps its own
  voice and is the origin of the factory framing. **Do not "fix" this back**
  without changing that decision first.

## The home page is now derived, not restated

`src/content/docs/index.md`'s hero tagline, meta description and `<title>` are
no longer hardcoded in the generator. They are lifted from the first bold line
of the superproject `README.md`, so the positioning sentence is authored in
exactly one place. The previous generator matched that line by its literal
wording, which meant changing the tagline would have silently printed it twice
on this page.
