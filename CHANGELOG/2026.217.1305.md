## What had drifted

The site's generated half had been publishing stale text since plugins#129 landed, because a sync
is only as current as the last time somebody ran it:

  covers plugin binaries). Fourteen generated pages still said "10 Testing Standards". Zero do now.
- **plugins#130** rewrote the encrypted-volume boot gate around the configured backend name.
- **plugins#132** corrected the docs generator's own recipe card, which had claimed the generator
  owns three top-level trees and never reads the hand-authored narrative. Both were false: it owns
  five entries, and it reads hand-authored pages to gate their links.
- **charly#215** projects the home page from `README.md` and publishes `GRIEVANCES.md`, and
  corrected three emitter descriptions that called the vision and grievances pages "verbatim" when
  both drop the source H1.

## Why the drift was invisible

Until charly#215 the generator could only ADD. A page whose generator was removed survived
forever, and `task docs:drift` reported "already up to date" while the generator no longer produced
it at all. The prune pass makes a page that stops being emitted show up in git as a deletion — this
sync is the first to run with that guarantee, which is why it can be trusted to be complete rather
than merely additive.
