The rest are rules the producing cutover added, each earned by a review round:

- **Deciding whether a file is generated: delete it and regenerate.** The question is whether the
  generator PRODUCES that path, not whether its bytes currently differ — an **in-sync carrier does
  not move**, and in-sync is the normal state of a correct change at review time.
- **A claim-keyed sweep produces a CANDIDATE list, never an EDIT list.** The sharpest case is
  sweeping a claim you have just corrected: the correction quotes the old wording in order to
  retract it, so the sweep's hits include the fix. **No pattern separates *asserting X* from *saying
  X was wrong*; they are the same string.**
- **Put the safeguard where the reader ACTS, not where it is true.** A page that knows `rm` is
  destructive and states it several hundred lines from the step that deletes a file has the
  knowledge and none of the benefit.
