### Why the marketplace pin is `5ce7132`, not main HEAD

`5ce7132` is marketplace#333's merge commit — **exactly `b40ca54` + one commit**, whose entire
content is the kind skill's prose plus its catalog rows:

```
$ git -C marketplace diff --stat b40ca54 5ce7132

```

Pinning to a main-HEAD marketplace would pull in unrelated corpus changes (including another
session's in-flight rewrites of the validator/rulebook skill pages); pinning to `5ce7132` keeps
this PR scoped to the kind docs. Those unrelated corpus changes are **not** in this PR.

### Why the charly CI-time pin is NOT bumped here

A charly-pin bump was attempted and **rejected**: with the current charly checkout and the pinned
`plugin-docs v2026.267.0941`, the generator emits `reference/cli/add-candy:box.md`-style pages —
the `:`-slug regression the docs skill documents. A charly-pin bump must ride a `plugin-docs`
bump in the same change; that is a separate cutover and is deliberately not folded in here.
