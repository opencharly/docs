# 2026.217.1921 — abbreviations, two shapes, nesting, and the generator-owned pages reworked

The original draft of this cutover (branch `fix/abbreviations`) was written before the
generator owned the home page and the reference pages, and carried a polymorphism model the
schema refutes. A fresh validator's nine findings split it into its parts; this is the
rework, with each part landing where its source lives.

## Abbreviations, on the hand-authored page

`IR`, `CUE`, `OCI`, `MCP`, `RPC`, `CalVer`, `ADE`, `RDD`, `SDD`, `SDK` and the probe
protocols (`CDP`, `VNC`, `ADB`) were used across the site with no consistent point of
expansion. [The abbreviations](/concepts/00-vocabulary/#the-abbreviations) is now a table on
the glossary page, expanding each one and saying what it means *here* rather than in general.
First uses on the other hand-authored pages are expanded inline and linked to that table.
The home page's expansions land through the generator — the superproject's `README.md` already
expands CLI, OCI, MCP, API and CalVer on first use, and `index.md` is regenerated from it, so
the home page was **not** hand-edited.

## Polymorphism: one keyword, two shapes

The old draft taught "they accumulate, they are not a choice between three types" — a claim
`charly box validate` rejects. The schema is a closed two-arm disjunction,
`#CandyValue: (*#Candy | #Image)` in `spec/schema/node.cue`: a candy carrying neither `base:`
nor `from:` is a **layer**; carrying `base:`/`from:` makes it a **box**. The two shapes are
mutually exclusive, and the only genuinely additive thing is `plugin:`, which lives entirely
inside the layer shape. The glossary page now says exactly that, with the worked
layer/box/plugin shapes restored as the demonstration the draft had deleted.

## The vocabulary itself is open — with the counts the validator re-derived

The catalog table now carries the corrected census: **123 words across 73 plugin candies**,
plus a further 14 words across 13 `plugin-example-*` fixtures, so the whole is 137 words
across 86 plugin candies — the same set the fixtures note splits rather than hides. The stale
"53 are compiled in" and "129 words across 81" figures are gone. `candy:` itself is a
plugin-provided kind.

## Nesting, kept

Capabilities compose a *candy* at authoring time; nesting places a *deploy* at run time.
There is no `nested:` field — nesting is position in the file, and the inner deploy runs
inside the outer one's venue. The section is unchanged from the draft, with a `venue` gloss
and the `from:` two-meaning note added.

- `index.md` hunks dropped — it is generated from the superproject's `README.md`, which
