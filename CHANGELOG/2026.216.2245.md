# 2026.216.2245 — a front page with a spine, and the grievances get a home

The landing page had no structure. It went: what it is → a roles table → four commands → four cards
restating the vision → a link list. A reader looking for "how does this actually work" had to
assemble the answer from three non-adjacent sections, and the tenet cards arrived before the
mechanics they are opinions about.

## Three sections, in reader order

**What it is** — two paragraphs. No headings, no tables, no comparison to tooling the reader may or
may not run.

**How it works** — one section, three subsections: [the words](/concepts/00-vocabulary/), the
one-keyword-three-roles table, and the four stages (build · run · deploy · evaluate) as a card grid.

**A real box, end to end** — the four commands against `tutorial-shell`, what the box deliberately
does *not* declare (an init system) and why, and the substrate swap.

Then where to go next.

## The vision is off the front page

The four "The bet" cards restated tenets 1, 2, 4 and 6 of [the vision](/vision/) — the thesis, not
the mechanics. The front page is not where a reader meets the thesis; it links to it instead of
paraphrasing a quarter of it. The freed card grid now carries the four stages, which is what a
reader at that point in the page is trying to learn.

The hero tagline claimed *"Every other tool hands an agent a sandbox and then spends its effort
taking things away."* Nothing verifies an assertion about every other tool. It is replaced by the
project tagline, which describes charly rather than its competitors.

## /grievances/

`GRIEVANCES.md` — four properties of ordinary container and VM practice charly is built to answer,
each with the status quo stated fairly and where the claim stops being true — is now **generated**
into this site by `charly docs generate`, exactly as `VISION.md` is, and sits in the sidebar beside
the vision. It was previously reachable only as a file in the charly repository.

It is a projection, not a copy: the only transformation is dropping the source H1 (Starlight renders
the frontmatter title) and rewriting the two repo-relative links onto site routes.
