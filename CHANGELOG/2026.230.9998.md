`charly#315` fixed two silent-loss defects in the docs generator. This is the leg that
makes them visible on the site, because the previous attempt fixed them **only at the
source** — and, as its validator put it, *a cure verified only at the source reads as
complete right up until you read the artifact*.

What ships here:

- **`reference/cli/feature.md` names both owners.** `feature` is served by two plugin
  candies — `plugin-feature` (top-level) and `plugin-box` (nested as `box feature`) — and
  both declarations are true. The emitter keyed pages by word and wrote one per PROVIDER,
  so the second write silently overwrote the first: 56 emitted, 55 written, exit 0, and
  `box feature` had no page at all.

  The page SUBTITLE needed the same cure and is fixed in the same leg. It read "served by
  THE plugin-box plugin candy" — a definite article asserting an exclusivity the body of
  the same page contradicts two lines down, and it is the search-result text, so it is
  read FIRST. Naming one owner is the identical clobbering the grouped body prevents, one
  field up; moving the name from one owner to the other would have preserved the defect
  while looking like a cure. The fact table is now keyed by owner too — it previously
  carried "Served by / Placement / Version" twice with nothing marking which candy each
  row described.
- **`reference/providers.md` counts distinct words.** It counted ROWS while saying
  "words", so `command` read "56 words" over a 55-word class — a page contradicting
  itself. The emitter defect is fixed: the page is internally consistent at 153 = 153,
  and the console figure agrees with the page it just wrote.

  **That figure is qualified, and the qualification is the honest part.** 153 is correct
  for the source population the generator can see, and NOT for the tree this entry lands
  on. `docs#70` added `reference/cli/ollama.md` and `reference/plugin/plugin-ollama.md`
  without regenerating `providers.md`; this leg merged that in. So on this commit the
  index reads `command — 55 words` while `reference/cli/` holds 56 pages, and omits an
  `ollama` row for a word carrying both a CLI and a plugin page in the same tree. Correct
  for this tree would be 154 / 93 / 62 / `command` — 56.

  The direction is uncomfortable and is stated rather than buried: `main`'s 56 was right
  BY COINCIDENCE — the `feature` double-count removed here was cancelling the missing
  `ollama` row. This diff fixes the internal defect and, on the merged tree, converts an
  accidentally-correct reader-visible figure into a visibly wrong one. Both are true.

  No regeneration fixes it here. Regenerating adds the `ollama` row but drops seven
  `command` words `main` has, because those come from `charly#315`'s unlanded `plugin-box`
  expansion. `charly#309` and `charly#315` are both open and NO TREE EXISTS that contains
  both source legs — a correct `providers.md` is not currently producible by anyone. It
  resolves when the later of the two lands.
- **`reference/candy/agentteams-snapshot.md` exists.** Stated as a SET difference rather
  than a count, because the counts do not reconcile the way a reader would assume: some
  reference pages are sourced from `box/*` submodule candies and have no directory under
  `candy/`, so "N directories vs M pages" compares two different populations. The
  checkable claim is the set-diff — every `candy/` directory now has a page, and before
  this leg exactly one did not: `agentteams-snapshot`, whose candy arrived in a merge
  whose projection was never regenerated. (An earlier draft said "332 directories, 333
  pages"; 333 was not a figure any single population produces.)

One page beyond the three cures is included and is named here rather than left to be
found: `reference/cli/marketplace.md` (+6/−2), a verbatim re-projection of the landed
`plugin-marketplace` description. It is clean content, but the scope sentence in an
earlier draft said residual drift was "deliberately NOT included" while this file is
exactly that — the description was wrong, not the diff.

The OTHER residual drift pages are deliberately excluded: they belong to other in-flight
