# 2026.215.1850 — the gourmet-kitchen landing, and a twelve-part concepts curriculum

The site had five concept pages in no particular order, a landing page that repeated the README's
lifecycle table, and a quickstart that opened by building a file the reader had never seen. This
rebuilds the hand-authored half around one audience — someone who already runs containers and VMs —
and one teaching order.

## The curriculum

`concepts/` becomes a glossary plus twelve pages, one per [vision](/vision/) tenet, in the vision's
own order. Every page uses the same skeleton, and the sameness *is* the pedagogy:

> the tenet, quoted · **The idea** (theory, no commands) · **In practice** (runnable, excerpted
> from a real committed candy) · **If you know …** (the delta from Docker / libvirt / Ansible /
> integration testing) · **See also** (links only, never a second explanation)

| Page | Tenet |
|---|---|
| `00-vocabulary` | — the words, defined once |
| `01-the-box-is-the-boundary` … `12-boxes-all-the-way-down` | tenets 1–12, in order |

Replaces `candies-and-boxes`, `candyboxing`, `lifecycle`, `rdd-and-ade`, `schema-and-versions`.

## The two things that were actually broken

**"box" and "candybox" were used interchangeably and never distinguished.** They are not the same:
a box is an image sitting in storage; a candybox is that image *running* somewhere isolated, and it
is the candybox's walls the security model talks about. `concepts/00-vocabulary` is now the single
canonical definition, and every other page links to it rather than redefining.

**Nothing showed a reader a `charly.yml` and then the commands that act on it.** The quickstart
opened with `charly box build fedora` — a build of a file the reader had never seen. It is now
config-first: read `tutorial-shell`, then build it, enter it, prove it.

## Every example is a real, tested candy

The rule is **excerpt, never invent**. Every fenced YAML block in the hand-authored pages is quoted
from a committed file and linked to its generated reference page:

| Role | Artifact |
|---|---|
| layer | `candy/ripgrep/charly.yml` |
| box | `box/fedora/box/tutorial-shell/charly.yml` (new, with a `disposable: true` bed) |
| plugin | `candy/plugin-example/charly.yml` |

This mattered more than it looks. The repository's own `charly.yml` entries are architectural R10
fixtures — accurate, and unreadable as teaching material. Rather than paraphrase them into
plausible YAML nobody executes, `tutorial-shell` was added upstream as a real box with a bed in the
acceptance roster.
